- **แบบทดสอบ:** 155 ชุด รวม 775 ข้อ (ตรวจคำตอบฝั่งเซิร์ฟเวอร์ พร้อมเฉลยและคำอธิบายละเอียด)

- **เกมฝึกทักษะ:** 155 บท (ครบ 100% ทุกบทเรียน ด้วยเกมฝึกทักษะ 7 แบบ)
- **ฐานข้อมูลและคลาวด์:** Cloudflare Workers + D1 (`learnphysics-db`) + R2 (`learnphysics-files`)

## ระบบ Deploy อัตโนมัติ (`deploy.yml`)

เมื่อมีการ push โค้ดขึ้นสู่ branch `main` GitHub Actions จะเริ่มทำงานทันทีตามลำดับดังนี้:

1. **Checkout:** ดึงซอร์สโค้ดล่าสุด
2. **Setup Node:** ตั้งค่า Node.js เวอร์ชัน 20
3. **Install dependencies:** ติดตั้งแพ็กเกจด้วย `npm install`
4. **Build:** คอมไพล์ Astro หน้าเว็บไปที่โฟลเดอร์ `dist/` ด้วย `npm run build`
5. **Deploy:** นำไฟล์เว็บและ Worker ขึ้น Cloudflare Workers ด้วย `wrangler deploy`

> [!NOTE]
> เวิร์กโฟลว์ Deploy จะ**ไม่มี**การรัน Seed ฐานข้อมูล เพื่อให้การอัปเดตรหัสหน้าเว็บหรือ UI ไม่ส่งผลกระทบต่อฐานข้อมูลจริงโดยไม่จำเป็น

## ระบบ Seed ข้อมูลบทเรียนอย่างปลอดภัย (`seed-d1.yml` & `build-seed.mjs`)

เพื่อป้องกันไม่ให้ข้อมูลผู้ใช้ (เช่น ความคืบหน้า `progress`, บุ๊กมาร์ก `bookmarks`, โน้ต `notes`, และประวัติการทำแบบทดสอบ `quiz_attempts`) สูญหายจากคำสั่ง `ON DELETE CASCADE`:

1. **เวิร์กโฟลว์แบบ Manual (`.github/workflows/seed-d1.yml`):**
   - เป็นเวิร์กโฟลว์แบบกดรันด้วยตนเอง (Manual Trigger: `workflow_dispatch`)
   - มีระบบป้องกันความผิดพลาด: ผู้ใช้ต้องพิมพ์คำว่า `SEED` ในช่อง `confirm` เพื่อยืนยันคำสั่ง
   - ทำงาน 2 ขั้นตอน:
     1. รัน `migrations/0006_seed_safety.sql` สร้าง UNIQUE index บน `quizzes(lesson_id)`
     2. รัน `migrations/0005_seed_all_lessons.sql` เพื่ออัปเดตบทเรียน

2. **สคริปต์สร้างคำสั่ง SQL ปลอดภัย (`scripts/build-seed.mjs`):**
   - **Upsert สำหรับบทเรียน (`lessons`):** ใช้ `INSERT INTO lessons ... ON CONFLICT(slug) DO UPDATE` เพื่อรักษาค่า `id` เดิมของบทเรียนไว้ ทำให้ตารางที่เชื่อมโยงกับผู้เรียนไม่ถูกลบ
   - **Upsert สำหรับแบบทดสอบ (`quizzes`):** ใช้ `INSERT INTO quizzes ... ON CONFLICT(lesson_id) DO UPDATE` เพื่อรักษาค่า `quiz_id` เดิมไว้ ไม่กระทบต่อประวัติการทำข้อสอบใน `quiz_attempts`
   - **ลบเฉพาะตารางลูกที่ไม่มีข้อมูลผู้ใช้:** คำสั่ง `DELETE` จะทำงานเฉพาะตาราง `videos`, `animations`, `games`, และ `questions` ของบทนั้นๆ ก่อนที่จะแทรกข้อมูลชุดใหม่เข้าไป
   - **ปลอดภัยแม้รันเดี่ยว:** ส่วนหัวของไฟล์ `0005_seed_all_lessons.sql` จะสร้าง UNIQUE index บน `quizzes(lesson_id)` เสมอ

## การอัปเดตเนื้อหาบทเรียนในอนาคต

เมื่อมีการแก้ไขหรือเพิ่มไฟล์ JSON ในโฟลเดอร์ `content/lessons/`:
1. รันสคริปต์คอมไพล์ SQL:
   ```bash
   node scripts/build-seed.mjs
   ```
   (สคริปต์จะสร้างไฟล์ `migrations/0005_seed_all_lessons.sql` ใหม่ที่เป็น UTF-8 อัตโนมัติ)
2. Commit และ Push ไฟล์ที่แก้ไขขึ้น GitHub
3. ไปที่แท็บ **Actions** บน GitHub เลือกเวิร์กโฟลว์ **Seed Lessons to D1** กด **Run workflow** แล้วพิมพ์ `SEED` เพื่ออัปเดตข้อมูลขึ้นระบบจริง
