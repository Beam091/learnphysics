# LearnPhysics

เว็บเรียนฟิสิกส์ภาษาไทย ม.ต้น ถึง ม.ปลาย
พัฒนาโดย Bunlai IT Group

## ตอนนี้มีอะไรแล้ว

- หน้าแรก พร้อมตัวอย่างจำลองการยิงวัตถุเฉียงขึ้น (ปรับมุมและความเร็วได้)
- หน้าหลักสูตร `/courses` แสดง 7 หมวด 34 บท 155 บทเรียนที่วางแผนไว้ (อ่านจากฐานข้อมูล D1 ผ่าน `/api/catalog`) พร้อมลิงก์ไปบทเรียนที่เปิดแล้ว
- หน้าบทเรียน `/lesson?s=ชื่อบท` มี 4 ขั้น: ลิงก์คลิป, ตัวจำลอง, เกม, แบบทดสอบที่ตรวจคำตอบฝั่งเซิร์ฟเวอร์ พร้อมเฉลยอธิบาย
- บทเรียนตัวอย่าง 3 บท: `projectile-intro` (มีเกม), `coulomb-law`, `light-reflection` ใช้คลิปที่ตรวจชื่อและลิงก์แล้ว
- ตัวจำลอง 3 แบบ (ยิงวัตถุ, แรงระหว่างประจุ, การสะท้อนของแสง) และเกม 1 แบบ (ยิงให้ตรงเป้า) อยู่ใน `public/engines.js`
- ความคืบหน้าของผู้เรียนเก็บในเครื่อง (localStorage) จนกว่าระบบล็อกอินจะเสร็จ
- ระบบหลังบ้านเริ่มต้น: เปิด `/api/health` แล้วต้องเห็นข้อความว่า `"ok":true`
- ฐานข้อมูล D1 `learnphysics-db` และที่เก็บไฟล์ R2 `learnphysics-files` สร้างแล้วใน Cloudflare โดยมีตารางครบ 14 ตารางตาม `migrations/0001_init.sql` และมีข้อมูลหมวด/บท (`0002`, `0003`) ใส่ไว้แล้ว และผูกไว้ใน `wrangler.jsonc` แล้ว (ยังไม่มีโค้ดที่ใช้งานจริง)
- ตัวอย่างโครงบทเรียน `content/lessons/_example.json`

## โครงโฟลเดอร์

| ที่อยู่ | หน้าที่ |
|---|---|
| `src/pages/` | หน้าเว็บแต่ละหน้า (`index.astro` คือหน้าแรก) |
| `src/layouts/Base.astro` | โครงที่ใช้ร่วมกันทุกหน้า: ส่วนหัว ส่วนท้าย ฟอนต์ |
| `public/` | สไตล์ (`styles.css`) ตัวจำลองและเกม (`engines.js`) หน้าบทเรียน (`lesson.js`) หน้าหลักสูตร (`courses.js`) และไอคอน |
| `src/worker.js` | ระบบหลังบ้านของ Cloudflare (ทุกอย่างที่ขึ้นต้นด้วย `/api/`) |
| `migrations/` | โครงตารางฐานข้อมูล D1 |
| `content/lessons/` | ไฟล์บทเรียน (คลิป แอนิเมชั่น เกม แบบทดสอบ) |
| `wrangler.jsonc` | การตั้งค่า Cloudflare |
| `package.json`, `astro.config.mjs`, `tsconfig.json` | การตั้งค่าของ Astro (เครื่องมือสร้างหน้าเว็บ) |

## นำขึ้นเว็บครั้งแรก

ควรทำบนคอมพิวเตอร์ จะง่ายกว่ามือถือ

1. **GitHub:** สมัครหรือเข้าสู่ระบบ แล้วกด New repository ตั้งชื่อ `learnphysics` กด Create repository
2. **อัปโหลดไฟล์:** แตกไฟล์ zip นี้ก่อน แล้วที่หน้า repo เลือก "uploading an existing file" ลากไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ข้างใน `learnphysics` (ลากเนื้อหาข้างใน ไม่ใช่ตัวโฟลเดอร์) ใส่ลงไป แล้วกด Commit changes
3. **Cloudflare:** สมัครหรือเข้าสู่ระบบ ไปที่ Workers & Pages แล้วเลือกสร้างโปรเจ็คจาก Git repository เชื่อมบัญชี GitHub และเลือก repo `learnphysics`
   - ชื่อโปรเจ็ค: `learnphysics` (ต้องตรงกับในไฟล์ `wrangler.jsonc`)
   - Build command: `npm run build`
   - Deploy command: `npx wrangler deploy`
4. รอให้ deploy เสร็จ แล้วเปิดลิงก์ที่ลงท้ายด้วย `.workers.dev` จะเห็นหน้าแรก ลองต่อท้ายลิงก์ด้วย `/api/health` ต้องเห็น `"ok":true`
5. ถ้าติดตรงไหน ให้คัดลอกข้อความที่ขึ้นหรือแคปหน้าจอส่งมาถาม

หมายเหตุ: ชื่อปุ่มบนเว็บ Cloudflare อาจต่างจากที่เขียนไว้เล็กน้อย เพราะหน้าเว็บปรับปรุงบ่อย

## รายการตรวจหลัง deploy ครั้งแรก

เปิดลิงก์ `.workers.dev` ของคุณ แล้วไล่ตรวจตามนี้ ข้อไหนไม่ผ่านบอกฉันได้เลย

1. หน้าแรกขึ้น และเลื่อนแถบมุม/ความเร็วแล้วกราฟเปลี่ยน
2. `/api/health` ขึ้นว่า `"ok":true`
3. `/courses` แสดง 7 หมวด รวม 155 บทเรียน และมีลิงก์บทเรียน 3 บท
4. เปิดบทโพรเจกไทล์: กด "เปิดบน YouTube" ต้องเปิดแท็บใหม่ ติ๊ก "ดูคลิปนี้แล้ว" แล้วรีเฟรช ต้องยังติ๊กอยู่
5. เกมยิงเป้า: ปรับค่าแล้วกดยิงจนข้อความขึ้นว่า "ถูกเป้า"
6. ทำแบบทดสอบทั้ง 3 บท ส่งคำตอบ ต้องเห็นคะแนน เฉลย และคำอธิบาย
7. ลองบนมือถือและเปิดโหมดมืด

## ขั้นต่อไป

1. ตรวจผล deploy ครั้งแรกและแก้ถ้ามีปัญหา
2. ระบบเข้าสู่ระบบด้วย Google และบันทึกความคืบหน้าข้ามอุปกรณ์
3. เพิ่มบทเรียนจริงตามแผน 155 บท (ต้องไล่รายคลิปจากแต่ละช่องก่อน)

หมายเหตุ: ไฟล์ใน `migrations/` ถูกรันกับฐานข้อมูลจริงไปแล้วทั้ง 4 ไฟล์ (`0001` ถึง `0004`) ถ้ารัน `wrangler d1 migrations apply` ภายหลัง ไฟล์ `0002` จะ error เพราะคอลัมน์มีอยู่แล้ว ให้บอกฉันก่อนรันคำสั่งนี้
